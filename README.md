# Navroʻz 3D Uy — 3D конструктор дома / 3D uy loyihalash

Один файл `index.html`, без сборки. Откройте в браузере (нужен интернет для three.js с CDN).
Bitta fayl `index.html`, qurishsiz. Brauzerda oching (three.js CDN dan yuklanadi).

**RU:** классический одноэтажный дом и двухэтажный «Наврўз»; прогулка внутри (WASD), редактор комнат и мебели, стиль фасада и крыши, ночной вид, отмена/повтор, линейка, ведомость материалов, сохранение проекта в JSON. Интерфейс RU/UZ.

**UZ:** klassik bir qavatli uy va ikki qavatli «Navroʻz»; uy ichida sayr (WASD), xona va mebel tahriri, fasad va tom uslubi, tungi koʻrinish, bekor/takror, chizgʻich, materiallar qaydnomasi, loyihani JSON ga saqlash.

Online: GitHub Pages (Settings → Pages → main / root).
